## 账号与环境

demo 限制在开发环境。首次创建随机管理员、操作员、只读用户，将凭证保存在 Git 排除的 `.data/demo-admin.json`；后续复用。管理员管理来源与用户，操作员运行/暂停任务和重放，只读用户查询。浏览器测试读取文件，日志不打印密码。

正式初始化使用显式 ADMIN_USERNAME/ADMIN_PASSWORD。Argon2id 密码散列，Cookie HttpOnly、SameSite Lax、生产 Secure，8 小时会话。登录检查同源 Origin，后续写请求携带 CSRF token；运行/重放携带 UUID Idempotency-Key。

生产 Caddy 使用专用 backend 网络上的固定 CADDY_BACKEND_IP，API 的 TRUSTED_PROXY_CIDRS 仅信任该地址。AIS_BACKEND_SUBNET 与该地址按部署主机现有网络协调配置；开发始终忽略伪造转发头。爬虫每次运行期限 CRAWL_RUN_TIMEOUT_SECONDS 默认 900 秒，超时进入可追踪失败。

Windows 的 Bun 脚本 shim 由 runner 转换为真实二进制路径，也支持 BUN_EXECUTABLE，保持 shell:false。Node 的 tsx 开发入口采用根配置以解析 Nest 参数装饰器。

## 演示和自动检查

demo 迁移、建立消费者/S3、创建来源任务、启动受控页及六个 worker、启动 API。Crawlee 采集分页 JSON，历史样例通过相同 RAW 管道写入；就绪检查 PG 和 CH。集成测试包含故障注入，应先停止 demo，文件顺序运行。浏览器测试自动管理 API/Web；开发允许复用，CI 使用新服务器。

默认 `start.ps1` 复用本地持久基础设施。演示采用两阶段恢复：先启动清洗、双写入与归档消费者，等待数据流压力解除；随后启动爬虫和采集消费者处理已有命令，等待全流允许采集后再派发新任务、发布 outbox 与历史样例。两阶段共享最多 120 秒的等待窗口。积压达到字节或时间压力门槛时，日志显示暂停原因和各流剩余消息，15 秒更新一次；配置/消费者拓扑异常直接报告，停止信号或子进程退出会中止等待。

恢复超时后，现有消息、数据库和归档数据继续保留。按提示检查消费者日志与未完成归档、采集任务，修复后重新启动。该流程沿用生产压力保护，历史消息通过正常处理及确认流程释放。

新采集任务在创建 run/outbox 前检查全流压力；暂停时 API 返回 503 与具体原因。相同幂等键继续返回已创建的运行记录。outbox 发布命令前再次检查全流压力，暂停时保留待发送记录。在途采集的 RAW 发布采用数据流门槛：保留 RAW、NORMALIZED 压力及全部拓扑检查，让已有命令在 COMMANDS 年龄压力下完成处理。

api:generate 用 Nest 与 Schema 导出 OpenAPI，再生成 Web 接口类型。修改公共契约后重新生成并类型检查。

## 基准含义

短模式 15 秒 100/s、5 秒 300/s、10 秒 100/s；完整模式采用计划 1,000/3,000 条速率及持续时间。每个原始响应展开 100 个位置，分别统计。另生成密集 30 天样例轨迹验证查询去重和抽稀。

查询使用 20 个不同只读用户的实际会话；身份初始化属于准备，登录由独立测试覆盖。可见延迟是一秒抽样和一秒轮询测得的上界；归档以每批最早接收时间计算保守 p95。报告记录硬件、实际速率、错误和未完成样本，容量门槛仅在完整模式满足全部条件后标记。

完整模式约产生 510 万持续位置、5 万密集轨迹、覆盖 50 万 MMSI；25.9 亿条累计历史属于专项规模验收。ClickHouse 容量统计覆盖开发数据库全部活跃位置分区，报告说明该范围。

## 动态个人技能开发

先执行包含 020 的数据库迁移，再为 API 与 Agent 同步设置 `AGENT_DYNAMIC_SKILLS_ENABLED=true`。地图展示继续需要 `AGENT_ENABLED=true` 和 `AGENT_UI_ENABLED=true`；模型密钥只注入 Agent。默认关闭时，个人技能与历史产物可读。实现边界、参数引用、版本发布、任务恢复与测试方法见[动态个人技能](agent-dynamic-skills.md)，生产配置见[运维说明](../infra/OPERATIONS.md)。
