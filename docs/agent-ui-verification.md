# 智能体界面感知与操控验收记录

实现日期：2026-10-15；收尾复核：2026-10-16。协议以 [agent-ui-protocol.md](agent-ui-protocol.md) 和 `packages/contracts/agent-ui.ts` 为准。

## 实现状态

| 环节     | 状态与行为                                                                   |
| -------- | ---------------------------------------------------------------------------- |
| 页面感知 | 应用根部登记路由；八个业务页面登记列表、编辑区和实际存在的详情/归档区        |
| 海图感知 | 组件挂载、打开、可见、焦点、浮层顺序、加载、人工交互、草稿及动作能力统一上报 |
| 页面绑定 | 消息绑定当前账号、会话和页面实例；页面代次与 worker 代次分别校验             |
| 执行通道 | 数据库命令账本、原子领取、执行前回执、终态后置条件校验、同任务续作           |
| 热图关闭 | 清除图层、图例、网格浮窗，取消热图请求与框选，阻止迟到结果恢复展示           |
| 热图生成 | 计算结果先保存；浏览器绘制后回执确认才回复已显示                             |
| 人工编辑 | 收起面板保留编辑组件；有未保存关系草稿时不允许智能体切换会销毁编辑器的页签   |
| 失败恢复 | 页面过期、取消、权限撤销和版本冲突阻止执行；执行结果不明不自动重放           |

## 组件与动作清单

| 标识                                               | 可用动作                                                     |
| -------------------------------------------------- | ------------------------------------------------------------ |
| `app.page`、`page.list/editor/detail/archive`      | 只读感知；其他业务页面不允许操控                             |
| `intelligence.draft`                               | 只读草稿状态，不外发草稿内容                                 |
| `workspace.left`                                   | 打开、关闭；船舶搜索、情报标绘、图层控制、时间回放、热图页签 |
| `workspace.right`                                  | 打开、关闭；对话、主动推送、任务中心页签；有草稿时限制切换   |
| `chart.layers.ais/tracks/evidence`                 | 显示、隐藏                                                   |
| `chart.viewport`                                   | 定位当前已选船舶；地图未就绪、拖动或绘图时阻止操作           |
| `chart.heatmap`                                    | 展示已有快照、整组关闭                                       |
| `chart.heatmap.legend`                             | 只读感知，随热图关闭                                         |
| `chart.heatmap.popup`                              | 关闭网格详情                                                 |
| `agent.reply`、`agent.input`                       | 收起、重新打开；条件框收起不提交回答或取消任务               |
| `agent.sources`、`chart.evidence`、`chart.choices` | 收起只读浮窗                                                 |

命令参数为固定枚举，不接收脚本、DOM 选择器、URL、SQL 或通用属性写入。实际可用动作以浏览器当前上报及服务端白名单共同校验为准。未挂载或未登记组件不能推断为已关闭。

重启复核过程中曾遇到 ClickHouse 全局内存限制，24 小时查询进入 `data_limit` 条件补问，未误报完成；后续复核同类查询成功。该资源限制属于当前运行环境边界，未通过扩大数据库内存或取消查询上限绕过。脚本将人工预置热图限定为最近一小时，自然语言生成仍请求 24 小时；若遇到超限，可通过真实条件弹窗缩短为一小时并验证原任务续作。最后成功运行的 `adjustments` 为空，因此本轮成功记录不声称执行过这条条件分支。

UI 专项隔离集成收尾复核 **7 项全部通过**，覆盖：同任务释放/重新领取、回执重复提交、其他账号与标签页、并发领取、任务取消、状态过期、组件版本冲突、页面代次变化、执行回执后浏览器丢失、伪成功后置条件、预算耗尽，以及领取后权限撤销。收尾运行日志保存在 `.data/agent-ui-final-integration.log`。

UI 操作使用本地有限语义技能，不调用外部模型。真实浏览器测试没有模拟 UI 命令接口、worker 或结果；这不等于验证了 DeepSeek 自由规划 UI 工具链。模型替身测试与跳过的真实模型测试按上述结果分别报告。

## 迁移、开关及复核

1. 迁移 `018_postgres.sql` 增加页面镜像、命令和回执表，扩展任务意图/状态及 UI 绑定、结果字段；保留已有业务表和结果。
2. `AGENT_ENABLED=true` 且 `AGENT_UI_ENABLED=true` 才开放 UI 能力。`.env.example` 保持 UI 默认关闭；本机验收在忽略提交的 `.env.local` 显式启用。
3. 通过 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start.ps1` 加载迁移和新版本，访问 `http://127.0.0.1:13001/`，刷新已打开页面以登记新实例。
4. 运行 `node --import tsx scripts/agent-ui-smoke.ts` 复核真实流程；会新增测试会话，只执行可逆界面操作。登录凭证从本机演示文件读取，不打印。
5. 专项隔离测试：`node --import tsx scripts/isolated.ts test:integration packages/infrastructure/agent-ui.integration.test.ts`，测试容器与开发数据分离。

关闭 UI 开关即可停止新界面操作；回退应用时保留命令和回执审计表，不执行破坏性数据库回滚。

## 当前边界

当前实现为全站语义感知、海图白名单操控。复杂自然语言或无法唯一确定的窗口会要求用户明确名称，不猜测目标；状态过期时明确要求等待同步后重试。页面变化不能接管旧页面命令，历史恢复不自动重放。业务保存、删除、审核、系统配置、跨页面导航、其他浏览器及桌面应用均未开放。

等待命令采用数据库持久化与轮询，心跳/绑定和状态更新合并在一个接口中，未单独实现协议后续设计里的通知中心和保存批准流程。浏览器回执缺失时标为未知并报告，要求用户核对后明确重新操作。
