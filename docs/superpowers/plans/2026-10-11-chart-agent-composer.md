# 海图悬浮智能体输入框实施计划

> 使用 subagent-driven-development 执行；用户提供的截图与移除底部栏要求作为本轮设计依据。

**目标：** 态势页中央海图占满可用高度，底部中央显示悬浮大模型输入框，右侧智能体协同展示同一会话的回复和任务。

**架构：** 态势页持有一个智能体会话实例，负责初始化、用户切换和轮询销毁。输入框与右侧面板共享该实例，发送时打开右侧 AI 对话。沿用显式区域确认、权限、配置及任务状态限制。

**技术栈：** Vue、Nuxt、TypeScript、现有 MapLibre、Vitest、Playwright、Bun。

## 视觉与交互

保持现有海图、左右面板与深蓝主题。中央底部表格和高度拖拽条移出态势页，海图扩展至中央容器底部。输入框采用青色描边胶囊、机器人入口、问题输入与发送按钮，宽度随中央空间收缩。船舶查询和专题结果继续由左侧搜索及右侧主动推送提供。

输入框支持 Enter 发送、Shift＋Enter 换行和中文输入法组合输入。配置未启用、只读权限、加载和活动任务状态有可见说明。服务开关、凭据和后端保持已有配置。
