# 公开海事情报采集

采集器将公开来源的原始响应按字节归档，再提取可审核事件。原文链接、段落、来源事实、坐标、时间依据和修订链分别保存。首次采集的事件进入 `candidate`；经人工确认的事件和关系支撑正式专题。

## 当前实现

2026-10-13 起增加 RSS、USGS 与六点海况，GDACS 改为全局 TC/TS/FL，worker 启动自动注册且独立调度七个预置来源。当前范围、迁移、检索协议和保留策略以[外部情报入库与 AI 检索](intelligence-search.md)为准。下文保留早期采集验证及历史回放方法，其中原中国近海 GDACS 过滤和旧迁移范围只描述当时版本。

## 早期来源与调度验证

预置来源位于 `apps/intelligence/source-presets.ts`。浙江海事航行警告由本站列表进入正文。上海海事门户的航行警告链接实际指向全国海事公告入口，采集器根据正文列表的“沪航警”筛选上海公告，来源名称保留这一入口关系。GDACS 使用官方 `EVENTS4APP` GeoJSON，筛选 TC/TS 中心点位于经度 105～135、纬度 3～45 的记录。该矩形是检索范围，中心点表明灾害记录位置，风暴覆盖范围需单独核查。

GDELT 使用官方 DOC2 `ArtList` JSON 接口检索中文航运新闻。文章索引观测时间与事件发生时间分别管理，地名或对象别名的命中形成“提及”候选。其 GEO2 接口提供新闻中的地点提及，按发生地点使用前需要人工证据审核。

用户已授权公开资料检索接入。预置配置逐项登记官方域名、授权标志、来源可信级别、每分钟 6 次请求、单并发、每轮最多 5 篇正文；海事每 30 分钟、GDACS/GDELT 每小时调度。所有正文、重定向、重试共享每轮请求预算，并通过既有 HTTPS、公开 DNS 地址、域名白名单、10 MiB 响应和超时策略。

```powershell
bun --no-env-file run intelligence:sources validate
bun --no-env-file run intelligence:sources register
bun --no-env-file run intelligence:sources ingest
bun --no-env-file run intelligence:sources --verify-local
bun --no-env-file run intelligence:sources replay-validation
```

`validate` 进行公开来源小样本采集，将原文、SHA-256、链接和解析结果保存到 `.data/intelligence-live-validation/validation.json`，同时查询 GDACS 2024 年台风 YAGI 的真实历史记录；此命令仅写本地验证文件。`register` 注册预置来源，已存在的配置由管理员当前设置控制；显式附加 `--replace` 可替换配置。`ingest` 注册后读取现存配置，跳过禁用来源，按既有 worker 锁逐项执行一轮归档及入库，保存统计和错误。`--verify-local` 重放已捕获原文并写入 `local-verification.json`，供离线检查。执行数据库命令前按顺序应用迁移 001 至 011，并配置既有 PostgreSQL、MinIO 和消息基础设施环境。

`replay-validation` 将先前真实抓取的原文重新解析、归档并入库，用于公开端点波动时的可复现验收。海事原文必须位于限定验证目录内，文件名、来源 ID、声明 SHA-256 与实际字节一致，原链接必须属于预置官方 HTTPS 域名；所有验证完成后才连接数据库写入。GDACS 历史原文与记录中的 YAGI ID、2024 年起始时间及坐标核对；早期历史清单未声明文件哈希，回放时据实际已保存字节计算哈希并标记 `local-computed`，供后续读取核验。

回放事件保留真实发布时间、历史起止时间、原文归档和候选状态，并在 `raw.replayEvidence` 记录抓取时间依据、原链接、字节哈希及回放模式。结果单独写入 `.data/replay-validation-result.json`，实时来源的最后请求时间和错误保持原记录。回放用于验证已取得的事实，当前新鲜度仍以实时请求状态判断。重复回放或相同内容的后续实时采集通过来源语义哈希复用当前版本。

## 时间、坐标与关系

中国海事正文发布时间按中国标准时间转换为 UTC。只有带“自／从／时间／于”和完整年月日的明确起止语义用于有效期。缺少可验证发布时间的正文保留原文待结构化。缺少有效期的公告以原文发布时间保存观测窗口，并标记 `effectiveTimeBasis: publication-observation-only`、`requiresEffectiveTimeReview: true`，进入待审核候选。GDELT 的 `seendate` 标记为索引观测时间并要求确认发生时间。界面和审核流程应显示这些时间依据，人工修订实际时间后方可用于正式专题。

规则识别度分秒、度分、小数经纬度、N/S/E/W 和中文经纬前缀；坐标必须包含半球，分钟和秒必须小于 60。正文位置默认生成“适用位置”候选，多个坐标保留为 MultiPoint，人工确认围合含义后可编辑为多边形。合法多边形的闭合、范围、面积和自交检查由契约及 PostGIS 保存流程执行。

对象名称或别名命中形成提及候选；原文几何与已登记对象的 PostGIS 相交形成发生／适用候选，关系类型跟随原文证据。规则提供审核线索，实际船舶影响需要独立的时间、影响类型及证据。GDACS 的可信中心点关系可标记为来源确认，事件本身仍待审核。

## 去重、修订与故障

海事及新闻的原文链接哈希、GDACS 的事件类型与事件 ID 构成稳定外部 ID。语义哈希包含原文事实、时间、段落和来源关系几何，并排除人工审核状态、版本号及规则生成关系。来源语义哈希保存在 `raw.sourceSemanticChecksum`；人工修订保留这一字段，重复轮询可识别来源内容未变并保留人工确认结果。相同内容重复轮询保留当前事件版本；来源内容变化递增版本并引用 `supersedesId`。原始字节归档按来源和内容哈希复用对象。

单篇正文失败记录 URL 和具体错误，并继续处理该来源的其它正文。来源级故障由 worker 分别记录，调度继续采集其它来源。部分失败和待结构化数量保留在来源状态中。

来源的最后尝试时间 `lastPolledAt` 每轮更新，最后成功采集时间 `lastSuccessfulAt` 仅在整轮解析、归档成功且没有正文失败时更新；等待人工结构化的已归档原文可算采集成功。网络、解析或部分正文失败均保留此前成功时间，并记录本轮统计与错误。这两个时间描述采集运行，原文发布时间和事件实际有效期仍由事件证据提供。原文回放独立记录，来源成功时间由实时采集更新。

## 已验证事实与复现证据

2026-10-11 的实际 HTTPS 请求取得浙江列表及正文、上海门户、全国海事沪航警列表及正文、GDACS 当前事件列表、YAGI 历史记录。浙江“新设灯桩—浙航警910/26”的原文坐标为 `30-30.90N 121-27.10E`，发布时间为 `2026-10-08 21:13`。GDACS YAGI 事件 ID 为 `1001090`，返回真实中心点 `[106.9, 21]` 和 2024 年事件起止时间；当前列表的 TC 中心均位于筛选矩形之外，因此当前导入数量为零是有效过滤结果。

本轮预置采集得到浙江 5 篇候选和上海沪航警 5 篇候选，均保留原文和时间待确认标志；历史 YAGI 验证得到 1 篇真实历史候选。GDELT GEO2 小样本返回 HTTP 404；DOC2 `typhoon China` 和预置中文航运查询返回 HTTP 200 空对象，未获得可解析报道。官方文档未确认该结构的空结果语义，采集器保留具体状态供核查；随后 `maritime` 和 `Shanghai`、7 天窗口的两次有限查询在 20 秒总时限内未完成，记录为请求超时。预置查询实时结果记录在验证清单中，以实际状态为准。采集入口可再次运行复现。

后续新鲜请求出现浙江端点 HTTP 504、重试预算耗尽时，可保留该故障状态，并使用已核对的原文回放验证归档读取、候选审核与地图关系。已保存原文的回放与实时采集分别记录，当前连通性、事件新鲜度和历史证据可分别检查。

测试使用经过裁剪的真实官方正文和 YAGI GeoJSON，保留真实事实并去除页面导航和无关子资源。覆盖重复、修订、移动坐标、时间缺失、非法坐标、新闻候选和单篇故障隔离。测试命令：`bun --no-env-file run test apps/intelligence/providers.test.ts apps/intelligence/adapter.test.ts`。
