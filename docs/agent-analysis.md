# 区域研判智能体

智能体以一次性分析任务组织区域研判。后台使用 Pi 1.1.0 的 `pi-agent-core` 与 `pi-ai` 连接 DeepSeek，复用港口限制船舶识别、区域低速活动与公告关联算法。精确 AIS、区域和证据保存在本地，模型接收结构化意图、统计、任务内代号和证据引用。

## 服务与运行

当前已接入全站路由感知与海图白名单操作，范围见[智能体界面控制协议](agent-ui-protocol.md)。通用 SDK、全站业务操作、确认与导航迁移按[目标架构](agent-sdk-architecture.md)和[路线图](agent-sdk-roadmap.md)推进。本文说明现有 AIS 智能体运行方式。

`apps/agent` 是独立 Node.js 24 工作进程。NestJS API 管理会话、任务与访问权限；PostgreSQL 保存任务权威状态、执行步骤和证据；独立 JetStream 队列投递任务。一次性任务与持续专题实例分别管理，用户提问按一次计算执行。

使用 Bun 安装依赖和执行工程命令。智能体相关迁移包括 `012`～`014`（会话、任务、输入与查询）、`015`～`016`（情报）、`017`（热图）和 `018`（界面客户端、命令与回执）。启动新版本 API 和工作进程前通过统一迁移入口执行全部待执行迁移。

```powershell
bun --no-env-file install --frozen-lockfile
bun --no-env-file run migrate
$env:AGENT_ENABLED = 'true'
bun --no-env-file run dev:agent
```

API 进程也需要 `AGENT_ENABLED=true`。默认功能关闭。模型密钥由工作进程环境中的 `DEEPSEEK_API_KEY` 提供；可通过明确的 Node `--env-file` 参数读取私有配置：

```powershell
node --env-file=.env.local --import tsx apps/agent/main.ts
```

本地 demo 在启用功能后启动智能体子进程。生产 Compose 提供 `agent` profile；为 API 与智能体配置功能开关，然后以 `--profile agent` 启动。密钥只配置给智能体服务。

| 配置                    | 默认值           | 用途                                              |
| ----------------------- | ---------------- | ------------------------------------------------- |
| `AGENT_UI_ENABLED`      | `false`          | 启用界面感知与海图白名单操作，依赖 Agent 开关     |
| `AGENT_ENABLED`         | `false`          | 启用接口与工作进程                                |
| `DEEPSEEK_API_KEY`      | 空               | 官方 DeepSeek API 密钥                            |
| `DEEPSEEK_MODEL`        | `deepseek-flash` | Pi 模型目录中的 DeepSeek 模型                     |
| `AGENT_THINKING_LEVEL`  | `high`           | 模型思考级别，支持 `high`（开启）与 `off`（关闭） |
| `AGENT_MAX_MODEL_CALLS` | `12`             | 每次任务的模型调用预算                            |
| `AGENT_MAX_TOOL_CALLS`  | `24`             | 每次任务的工具调用预算                            |
| `AGENT_MAX_RECORDS`     | `50000`          | 单次查询记录上限                                  |

模型思考默认开启，覆盖普通咨询、区域研判、情报总结与动态技能生成的模型请求。`AGENT_THINKING_LEVEL=off` 可关闭模型思考；工具循环继续按任务执行，模型和工具调用次数分别由 `AGENT_MAX_MODEL_CALLS`、`AGENT_MAX_TOOL_CALLS` 管理。思考内容供模型内部推理使用，界面和会话结果保存最终回复与执行步骤。

开启思考后，普通咨询每次模型请求的输出 token 预算为 8192，其他请求为 16384，供思考与最终回复共同使用；关闭后沿用各路径原有预算。思考可能增加响应耗时，任务继续受执行时限和调用次数预算管理。修改此配置后重启 Agent 工作进程生效。

## 使用与权限

### 情报检索

新增 `intelligence_search` 意图和独立结果，固定本地检索、读取、海况和来源状态四个工具。支持新闻、航警、灾害与点位海况，并在对话和回复浮卡中显示版本绑定引用。关键词补问使用 `topic` 字段，历史情报时间独立于 AIS 窗口，海况使用未来预报窗口。新增迁移 `015/016_postgres.sql`、来源与保留策略见[外部情报入库与 AI 检索](intelligence-search.md)。

### 条件选择与船舶查询

区域、船舶、时间和目标通过结构化输入请求补充。助手新请求自动弹出选择框；关闭只收起，确认后同一任务自动继续，不必再次发送“开始”。历史恢复显示卡片，点击“继续选择”重新打开；存量旧任务可以按原条件重新开始。

“当前视野有哪些船舶”采用发送时地图范围、来源、船型及最新报告筛选，通过本地最新船位查询返回准确总数和前 100 艘，不将地图聚合点当名单。单船基本信息也在本地查询，查询回复不调用外部模型。历史分析支持区域与所选船舶共同过滤，时间窗口可选快捷时段或自定义起止。

输入请求和任务状态在同一事务中更新，等待期间释放 worker。步骤、结果和摘要绑定 inputRevision；改变条件不能复用旧范围结果。模型/工具预算累计，耗尽明确失败，用户选择新尝试后才使用独立预算。详细接口、恢复和界面隔离规则见[对话条件选择协议](agent-ui-protocol.md#对话条件选择与任务续作)。

### 普通咨询与区域研判

消息提交与工作进程使用同一分类器区分普通咨询和区域研判。问候、当前北京时间或日期查询、系统能力咨询可以在未确认区域时排队，并通过 Pi 调用 DeepSeek 生成回复；区域研判继续要求明确的分析区域和目标。普通咨询的结果版本为 0，回复保存为会话消息，模型调用次数按实际请求计入任务。

普通咨询向模型发送固定的语义意图与平台能力说明，用户原文和历史对话保存在本地。时间查询经模型确认唯一的 `CURRENT_TIME` 语义标记后，由平台读取服务器时钟，按 `Asia/Shanghai` 规范呈现时间句并保存本地时钟快照；显示的时间对应回复生成时刻。模型措辞及其附加的日期、星期等断言由平台时间句统一替换。匹配采用完整语句，混合分析指令或含私密字段的后缀继续进入原业务意图流程。当前普通咨询范围为上述三类，其余目标按已有支持范围补充条件。

插入普通咨询后，分析追问绑定最近的业务任务，保留原分析区域、证据版本和未完成的补充条件。普通咨询的完成状态与算法空结果分别呈现，发送错误由对应操作成功后清除。

工作进程先完成消息拉取并关闭拉取监听，再执行模型或算法任务，任务结束后确认消息。拉取监听的心跳与耗时任务分别管理，慢模型回复保持任务租约和执行权限检查；失败任务继续按原队列规则重试。时钟快照由当前有效执行者更新，分析输入与证据步骤保持既有幂等规则。

本地 `start.ps1` 演示由 `scripts/demo-workers.ts` 统一分配工作进程指标端口：两个专题分别使用 `13108` 和 `13109`，智能体使用 `13110`。工作进程沿用继承的应用配置，指标端口按进程角色显式设置；本地 Prometheus 抓取包含智能体端口。生产 Compose 中的独立容器继续使用各自既有端口。

用户在海图确认当前视野作为分析区域，选择历史小时数并输入目标。默认分析过去 24 小时，最长 168 小时。区域采用边界框，跨日期变更线沿用现有空间规则。低速算法默认阈值为 3 节、至少 3 个观测点和 60 分钟窗口。

操作员与管理员可创建一次性分析任务；会话、任务和证据按创建者隔离。持续专题的创建和启停沿用管理员权限。执行时重新校验角色，任务取消或执行代次变化后，旧执行结果不能推进任务。

会话接口位于 `/api/v1/agent`，提供配置、会话创建与读取、消息提交、任务详情、取消与事件补取。提交消息携带 UUID `Idempotency-Key`；相同请求重试复用该键，改变请求内容时使用新键。事件按游标读取，支持刷新后恢复任务状态。

追问绑定明确的前置任务及结果版本。解释已有结论时复用证据；明确提出新的分析目标时创建新运行。追问中改变区域或时间范围会进入补充条件流程，任务保存原始证据与新请求范围。工作进程设有 180 秒任务执行时限，专用 PostgreSQL 连接设置 60 秒语句超时及 5 秒锁等待超时。

## 模型外发与证据

外发网关采用字段白名单。用户自由文本先在本地提取支持的结构化意图；原始文本、精确坐标、船舶标识、完整公告和后台错误保留本地。模型工具通过区域代号和任务上下文绑定本地参数。

模型只引用当前结果版本中的证据编号。完整算法证据通过已鉴权的任务详情供海图定位。观测、规则匹配、解释与局限分别呈现；低速活动与公告共现支持关联描述，行为原因需要进一步证据。

未知请求进入补充条件流程。数据不足、无匹配公告、无匹配结果和查询超限分别报告。大型历史查询应按任务范围缩小后重试，并根据实际工作负载开展容量验证。
