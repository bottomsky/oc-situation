# 船位海图工作台

海图工作台使用顶部系统导航、左侧人工操作、中央全高地图与右侧协同面板组织业务。中央底部提供悬浮大模型输入胶囊，船舶查询和专题结果分别通过左侧搜索与右侧主动推送访问。公共导航连接已有页面，海图页使用深蓝、青色主题。船位、专题结论、任务状态和证据来自现有服务。

AIS 监控、智能研判、任务管理、数据分析和系统设置共用工作台的深蓝、青色配色，覆盖来源、专题、公告、任务、运行、质量、重放和账号页面。表单、指标、表格、原文详情和提示状态采用共享颜色变量；成功、等待、异常和停用状态分别使用绿、黄、红和灰蓝色。

## 页面操作

当前回复浮卡、完整对话和海图白名单操作见[智能体界面协议](agent-ui-protocol.md)。独立通知、通用临时标绘、全站操作与导航按[SDK 目标架构](agent-sdk-architecture.md)和[路线图](agent-sdk-roadmap.md)推进。以下说明当前页面行为。

顶部搜索支持船名、MMSI 和 IMO。提交后进入海图页并展开搜索结果；再次提交相同关键词可以重新查询。搜索结果保留分页，选中船舶后查看档案、字段来源和历史轨迹。

左侧人工操控面板默认收起，通过海图左上角“人工操控”按钮打开，提供“海洋态势”“船舶搜索”“情报标绘”“图层控制”“时间回放”“历史航线”“AIS 热力图”和“航行预测”八项功能。关闭后移除面板占位和常驻快捷工具栏，将空间交还海图；搜索导航或点选船舶仍可按需打开详情。右侧协同面板开关与图层选择按本机登录账号保存。图层开关控制图形显示，采集与专题计算由后台继续管理。

“海洋态势”统一管理船位时间范围与人工关注对象。默认加载最近 24 小时内有报告的船舶，每艘显示最新一条船位。快捷范围覆盖 15 分钟至 30 天，自定义支持分钟、小时和天，按整分钟设置，点击“应用范围”后更新。时间范围随当前时间滚动，实时更新会移除已超出范围的船位；暂停更新时保留当前结果。账号分别记住已应用的时长，HTTP 快照、实时订阅和 AI 海图上下文共用同一范围。

人工关注清单纳入“海洋态势”，船舶、航线和事件共同遵守 100 个对象上限。选中船舶后可加入关注，名称打开详情，移除按钮与清空操作分别管理集合。修改船位时间范围保留关注清单，关注引用继续供人工和 AI 研判使用。业务对象保留原有添加和地图展示能力，地图空间用于船位与分析图层。

功能入口按标签自然宽度排入顶部单行，当前功能始终显示在顶部，其余入口按可用宽度分配到“更多功能”菜单。面板宽度、窗口尺寸和字体变化后重新计算；全部功能可以容纳时收起菜单入口。菜单通过 Portal 挂载到页面浮层并向下展开，长菜单支持独立滚动。首次访问业务视图后保留其状态，切换功能或折叠面板后，情报筛选、勾选及历史航线、热力图等表单草稿继续保留。

键盘 Tab 可进入当前功能和“更多功能”入口。顶部页签支持左右方向键切换，Home 和 End 切换至首尾可见功能；菜单支持方向键浏览、Enter 选择和 Escape 关闭。菜单选中功能后将焦点交给顶部当前页签，按 Escape 关闭菜单后恢复“更多功能”按钮焦点。

情报列表使用统一卡片，左上角复选框负责批量勾选，标题和正文负责打开证据详情，右下角“⌖ 定位”按钮负责海图定位。三个操作独立响应；当前详情高亮与批量勾选分别呈现。标题为复选框留出空间，摘要、来源、时间与状态随卡片宽度换行，选中详情时保持卡片尺寸。

桌面工作台支持拖动左右面板边缘调整侧栏宽度。尺寸按本机账号保存，刷新和折叠后可以继续使用。中央地图占满可用高度，悬浮输入框随中央空间调整宽度。窗口缩小时，显示尺寸依据海图剩余空间收缩，原有侧栏尺寸偏好保留；中屏左侧浮层、窄屏左右抽屉沿用原有布局。

中央保留标题与地图操作栏，视野船舶、最近专题结论、平台实时连接及来源标签所在的整排状态栏已移除，地图获得更多可用高度。船舶查询和专题结果继续由左侧搜索与右侧主动推送提供。

侧栏分隔线支持键盘操作：左右方向键调整宽度，按住 Shift 可增加每次调整幅度。双击分隔线或按 Home 恢复默认尺寸。拖动过程中复用海图实例和实时连接。

左侧搜索结果提供单船记录和档案入口。海图在全部缩放级别使用完整单船快照，远景显示小点，近景显示方向与船形；密集位置提供重叠船舶选择。快照按页加载，新视窗全部加载完成后替换上一完整结果，实时更新按快照与序号衔接。容量限制与加载失败通过状态提示显示。旧地图接口继续兼容已有调用方。

右侧主动推送提供最近 30 条专题结论和选中状态。有效、修订和撤回状态保持可见。打开结论后可查看原始 AIS、公告段落、规则步骤、参数和历史版本；定位操作高亮对应版本的地图证据。查看历史版本时保持该证据快照，实时推送继续更新列表。

证据支持放大阅读。放大窗口使用原生模态对话框，Tab 与 Shift+Tab 在窗口内循环；Escape 关闭后恢复触发按钮焦点。地图快捷键在模态窗口打开期间暂停响应。

任务中心展示专题实例，选中实例后读取其运行记录。管理员和操作员按专题启停及运行条件发起人工计算。采集任务和完整运行日志通过已有管理页面查看。

右侧默认显示 AI 对话。中央悬浮输入框、当前回复浮卡与右侧面板共享同一智能体会话，发送问题后右侧切换至对话页签并保持原有开关状态，左侧当前页签、情报筛选和选择继续保留。机器人入口可打开同一对话面板。输入框支持 Enter 发送、Shift＋Enter 换行；中文输入法组合输入期间，Enter 用于完成输入。

当前回复浮卡展示 AI 头像、业务类型、执行状态、时间及对应的持久化助手消息。单对象优先右上布局，多对象按组适配视野并将卡片放在组范围右侧，分散对象采用地图顶部居中布局。地图保留逐对象高亮，卡片与对象通过底部名称关联。每轮输入代次最多自动适配一次；船位更新、正文增长和面板开关只更新投影与排版，主动“重新聚焦”可再次适配。

卡片底部淡分隔线下最多展示三个对象名称，窄屏一个；“查看更多”打开独立右侧关联对象抽屉，支持搜索、类型筛选和每页 50 条分页。名称打开船舶或情报详情，“定位”单独调整视野。船舶详情展示最新资料，情报详情标明当前读取版本；回复引用时间与版本分别保留。未定位对象仍保留详情入口，超出快照范围的数量单独说明。情报名称的详情读取保持当前地图集合。

右侧对象抽屉与左侧详情可以并存，关闭详情保留列表，关闭列表恢复原右侧协同内容，Esc 每次关闭一层并恢复触发焦点。下一次发送替换浮卡，右侧完整问答继续累积。关闭浮卡保留消息与任务，当前回复后续更新维持隐藏；新建、切换、刷新及账号变化后，通过右侧恢复历史。头部“查看完整对话”图标打开右侧并定位同一条消息，回复的消息标识与正文保持一致。

发送失败保留当前问题、草稿与错误。问题已提交但状态读取失败时，保留已受理的任务绑定并提示重新读取，读取恢复沿用既有轮询。卡片正文支持滚动，窄屏保留输入与关闭操作的空间；阅读浮卡或历史消息时，滚轮及键盘操作保持海图视野。

问候、当前北京时间或日期查询、系统能力咨询支持未选区域发送，并显示实际模型回复。区域研判在补齐分析区域后执行。新消息在用户刚发送问题或已经位于对话底部时跟随显示；用户阅读历史消息时保留滚动位置。普通咨询按助手回复呈现，任务详情中的算法空结果提示用于真实分析任务。

悬浮输入框默认空白且未聚焦时采用高透明背景、弱描边和无发光样式。文本输入区域聚焦或草稿非空时高亮描边，背景保持透明；有文字时失焦仍保留高亮，清空并失焦后恢复静态样式。键盘导航到按钮时显示独立焦点提示。

配置未启用、只读权限、初始化和活动任务状态通过输入框提示说明，发送状态遵循已有权限与任务限制。发送流程沿用显式区域确认和既有会话服务。界面与会话交互的历史验收使用受控响应；真实模型调用按具体任务和日期单独记录。天气、碰撞预测和航线规划继续显示接入状态，新增算法和服务可沿既有业务边界扩展。

## 开放海事底图与 GIS 操作

默认视野覆盖黄海、东海，范围为东经 118°—128°、北纬 28°—41°。地图使用 WGS84 坐标定位，提供深色研判和浅色海图样式、比例尺、经纬网、经纬度指示、海里测距及按需船舶标识。

地图资源从随前端部署的版本化 manifest 读取，首期覆盖东经 105°—135°、北纬 3°—42°。已安装的 OSM 简化陆地和港口要素记录来源、许可、数据时间、校验值及显示精度；航海要素按实际可用状态展示。Natural Earth 保留为加载回退。简化展示陆地与后端精细避陆数据分别管理，数据安装与概率模型说明见[海事 GIS 与概率预测](maritime-gis.md)。

图层控制提供船位、轨迹和证据三个显示开关，本机保存业务图层偏好。航迹默认按时间着色，可切换航速；起终点、停留、方向和悬停信息采用统一样式。观测缺口及日期线保持分段。图源与船位采集分别管理。

“航行预测”入口支持单船即时预测和最多 20 艘关注船，未来位置与沿途经过使用独立概率视图。右侧展示已审核航行警告的影响、首次进入时间和原文证据。结果显示数据与计算时间、版本、未校准状态及适用条件；历史结果保持快照，当前数据或情报变化后提示重新计算。

## AISStream 来源

[AISStream](https://aisstream.io/documentation) 提供 AIS 实时消息，由现有后端采集器接入。密钥通过后端 `AISSTREAM_API_KEY` 配置，管理员在数据来源页面确认授权并启用来源。采集区域由来源配置管理，地图视窗只改变平台内的数据查询范围。

本机私有配置保存在 Git 忽略的 `.env.local`。`start.ps1` 使用 Node 的环境文件参数读取配置，后台进程继承密钥；来源通过 `secretRef` 引用环境变量名称。来源页面管理允许域名与授权确认，采集范围通过来源配置接口设置，页面中的范围输入入口纳入后续完善。密钥值保留在后台配置中。

来源状态按启停、最近接收时间和请求错误显示；平台实时连接状态表示浏览器与本系统之间的连接。合成观测继续保留样例标记。

## 响应式布局与验证

宽屏展示完整三栏；中等宽度默认折叠左侧操作面板，展开时采用浮层；窄屏通过抽屉访问两侧功能区，中央保留全高地图与自适应悬浮输入框。地图尺寸变化使用 `ResizeObserver` 合并更新，视窗查询采用 150 毫秒去抖。页面退出时清理观察器、事件与定时器。

自动化验证检查本地地图样式、业务图形和图层开关，以及拖动、缩放和旧偏好恢复期间的外部图源请求数。业务浏览器验收运行 `bun run test:e2e:isolated`，使用独立数据库和队列，并保留四艘合成样例船及两个专题的验证链路。

悬浮输入框的历史单元、浏览器及截图验收见[2026 年 10 月 11 日记录](reports/chart-agent-composer-2026-10-11.md)。记录保留受控 AI 响应与当时环境边界，当前交付状态统一见[实施状态](implementation-status.md)。

完整生产前端验收先执行 `bun run build`，再在 PowerShell 中运行：

```powershell
$env:E2E_COMPILED_WEB = '1'
bun run test:e2e:isolated --retries=0 --compiled-smoke
Remove-Item Env:E2E_COMPILED_WEB
```

此模式通过测试网关组合编译后的 Nuxt 前端和隔离 API，保持 Cookie、Origin 与实时 WebSocket 转发，使用与开发模式相同的浏览器用例。测试网关负责本机验收；正式部署沿用现有 Caddy 配置。

## 本地运行

在项目根目录执行 `./start.ps1`，默认启动完整演示。海图入口为 `http://127.0.0.1:13001/`；后台、来源配置和数据库沿用既有启动流程。业务组件使用现有 API 与数据结构，启动配置与部署顺序见[运维说明](../infra/OPERATIONS.md)。
