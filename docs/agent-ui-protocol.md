# 智能体业务界面协议

## 状态与适用范围

本文记录当前实现的对话条件选择与海图界面控制。条件选择支持区域、船舶、时间和目标补问，海图命令支持已注册组件的查询与临时操作。业务保存仍通过现有业务页面与权限执行。

通用 SDK、全站业务操作、动态能力、审批、独立通知与导航切换的目标设计统一见[SDK 架构](agent-sdk-architecture.md)，任务依赖、写域、迁移与验收见[路线图](agent-sdk-roadmap.md)。现状接口以 `packages/contracts/agent-ui.ts` 和对应控制器为准。

条件选择、查询与任务续作使用现有 `AGENT_ENABLED=true`。界面感知与海图操作需要同时启用 `AGENT_UI_ENABLED=true`，后者默认 `false`。2026-10-15 已实现语义组件注册、页面镜像、命令账本与回执续作；业务保存确认中心、独立通知通道及其他目标扩展仍未开放。

### 已实现的界面控制子集（2026-10-15）

当前实现以 `packages/contracts/agent-ui.ts` 的严格契约为准。全站登记当前路由；海图登记左右面板、页签、AIS/轨迹/证据图层、热图与图例/网格浮窗、回复浮卡、条件框、来源与证据弹窗、重叠情报选择、视野及人工交互锁。未登记的界面不推断为已关闭。

`ui-control` 是本地有限语义技能，登记 `ui.list_capabilities / ui.get_state / ui.execute / ui.get_command`。用户文字、组件内容和坐标不外发模型。支持查询当前打开界面、面板开关/页签、图层显隐、已选船位定位、只读浮窗收起、条件框收起/重新打开，以及热图展示/整组关闭。任意页面导航、业务保存/删除、配置更改和丢弃草稿不在白名单。

热图整组关闭取消该展示的加载和框选，清除图层、统计图例及网格浮窗，保留历史结果和人工操控面板。组件版本和展示代次共同拦截迟到结果。生成任务保存查询结果后创建展示命令；只有地图绘制后的回执通过后置条件检查，任务才回复“已显示”。关闭期间完成的计算可保留为历史结果，但不自动恢复展示。

现有输入框允许数据任务进行期间提交界面指令。worker 使用有界的界面任务处理通道，避免长时间模型或数据调用阻塞关闭操作。所有任务仍通过 PostgreSQL 租约和代次领取；浏览器等待期间状态为 `waiting_ui`，释放 worker。

当前 HTTP 子集位于 `/api/v1/agent/ui`：

| 接口                                         | 实现语义                                                         |
| -------------------------------------------- | ---------------------------------------------------------------- |
| `POST /clients`                              | 按账号注册独立页面实例                                           |
| `PUT /clients/:id/state`                     | 严格状态快照、序号检查、会话/路由 CAS 换绑与续租合并在一个事务中 |
| `GET /clients/:id/commands?pageGeneration=…` | 当前实例尚未结束的命令，最多 100 条；不提供历史执行资格          |
| `POST /commands/:id/claim`                   | 原子领取，返回 30 秒令牌；热图展示载荷仅从该任务持久结果读取     |
| `POST /commands/:id/receipts`                | `executing` 先落库；终态回执验证后置条件并将原任务重新排队       |

页面变更约 100ms 合并上报，当前轮询每 1.5 秒同步状态及命令，失败后 5 秒重试；同时完成心跳，租约 30 秒，服务端状态超过 10 秒视为过期。消息和显式重试可携带 `uiBinding`，目标由已验证的页面实例及代次固定。刷新生成新实例，历史会话恢复不重放命令。命令到期或页面失效时，未执行命令过期；已进入执行的命令标为 `unknown`，只报告未确认，不重放。

迁移 `018` 增加客户端、命令和回执表，以及任务 `ui_binding/ui_result`、`ui_control` 意图和 `waiting_ui` 状态。旧消息、查询及结果接口保持兼容；旧任务没有页面绑定时不会自动操作新页面。部署顺序为先迁移，再更新 API/worker/web，最后按需启用开关。回滚应用前关闭 `AGENT_UI_ENABLED`，保留审计表，不做破坏性回滚。

独立 heartbeat/binding、通用数据引用、保存确认和通知接口在 SDK 路线图中管理，当前状态上报仍合并续租。

组件与动作清单、迁移及复核步骤见[界面控制验收记录](reports/agent-ui-verification-2026-10-16.md)。

## 对话条件选择与任务续作

### 请求、回答与界面

`request_input` 只接受固定字段 `region/vessels/time/goal/topic` 和补问原因枚举。浏览器按业务控件渲染，模型不能提供表单代码。`ask_user` 兼容入口使用同一持久补问服务。输入请求绑定账号、会话、任务、inputRevision 和 pauseGeneration，不绑定浏览器页面实例；刷新后用户可以手动重新打开并回答。

字段支持当前视野或矩形框选、按船名/MMSI/IMO 搜索及最多 100 艘多选、最近 1/6/24/72/168 小时和自定义起止。时间显示为北京时间，后台保存 UTC；历史窗口最长 168 小时且位于最近 30 天。区域、船舶、时间共同限制分析；单船详情只要求船舶。明确提及当前视野时，采用发送时的范围和筛选快照，后续地图移动不改变任务。

当前页面新请求从消息响应或事件去重发现后自动打开一次；历史恢复只显示卡片。关闭/Escape/遮罩只收起，decline 对应“取消本任务”。轮询不覆盖正在编辑的草稿。矩形选择使用独立捕获层，不能清空人工 TerraDraw 草稿；船舶搜索独立维护状态，不改变人工详情和轨迹。

### 接口与事务

| 接口                                                               | 职责                                                                          |
| ------------------------------------------------------------------ | ----------------------------------------------------------------------------- |
| `POST /api/v1/agent/sessions/:id/messages`                         | 可选 mapContext 捕获视野与选择；仍创建独立任务                                |
| `POST /api/v1/agent/tasks/:id/input-requests/:requestId/responses` | 使用 Idempotency-Key、inputRevision、accept/decline；accept 包含结构化 values |
| `GET /api/v1/agent/sessions/:id`                                   | 同一一致读快照返回消息、任务、pendingInputRequests、snapshotCursor            |
| `GET /api/v1/agent/tasks/:id`                                      | 返回当前修订步骤、分析结果、queryResult 和待补充请求                          |
| `POST /api/v1/agent/tasks/:id/retry`                               | 用户显式建立关联原任务的新尝试，预算独立                                      |

values 允许 bbox、mmsis、timeRange、filters、purpose；快捷窗口使用 historyHours，不能同时提交 timeRange。目的枚举为船舶列表、船舶详情和现有两类区域研判。接口沿用认证、角色、Origin 与 CSRF 保护，精确参数只在本地业务通道使用。

创建请求、任务转 awaiting_input、释放租约和追加事件同事务完成。回答先鉴权，再按会话、任务、请求顺序加锁，核对状态、输入修订及挂起代次；规范选择、保存回答和本地消息，将**同一 taskId** 转 queued。已有可运行任务扫描与 JetStream 负责唤醒。等待用户不占 worker，也不计入 180 秒执行窗口。

同幂等键同内容重试返回原结果，不同第二次回答或已失效请求返回冲突。输入请求没有保存批准的五分钟期限；取消、权限撤销或请求替换使其失效。时间超过保留期则返回可修正错误并保留待补状态。只有明确取消任务才结束该请求。

### 版本、结果与恢复

inputRevision 表示规范输入修订，generation 隔离 worker，resultVersion 表示单调递增的持久结果版本。步骤按 task/inputRevision/stepKey 保存；结果和摘要绑定输入修订。输入变化后重算相关数据，旧结果只作历史，不能用旧 resultVersion>0 判断当前完成。

分析需要当前修订的算法结果和有效摘要，允许空结果；查询需要当前修订的持久 queryResult 和本地摘要，允许 total=0；普通咨询需要有效回复。列表总数、前 100 艘和查询时间来自同一 PostgreSQL 快照，不能使用地图聚合点代替名单。最新船位查询不等同于历史完整船舶查询。

模型/工具预算不因回答重置。预算耗尽为 failed/budget_exhausted，提供显式新尝试，不能进入补问循环。新尝试绑定来源任务和具体输入/结果版本，保持已确认的绝对时间，不复制旧预算和工具完成账本。模型请求从持久白名单投影重建，精确坐标、标识、时段和用户原文保留本地。

会话快照与 snapshotCursor 来自同一一致读边界，继续复用 agent_events 和 2500ms 串行轮询。写事务先锁会话再分配事件 ID，保持提交安全的游标。恢复事件只更新记录，不重做操作。存量等待任务保留历史与文字补充链，可通过“按原条件重新开始”进入新闭环，不伪造历史请求。
