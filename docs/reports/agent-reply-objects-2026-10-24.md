# AI 回复卡与关联对象交互改版记录

## 目标与基线

实施用户已确认的回复卡改版：对象自身高亮、单对象右上布局、多对象组范围布局、底部可点击对象名称，以及右侧关联对象抽屉。基线提交为 `aa12bdc`，保持免费图源、AIS 单船数据、历史快照及任务回执兼容。

## 实施与验证边界

展示、地图、集成分别由子智能体在明确的独占写入范围实施，主会话维护共享模型并审查。对象引用保留版本与来源任务，几何归并为业务对象；名称读取详情，定位独立操作。右侧对象抽屉与左侧详情分别管理打开状态。

本次测试使用独立副本、本地地图夹具及浏览器验证。原工作区 Nuxt 缓存和 13000/13001 服务保持独立。代码保持仓库 LF 配置，使用 Bun 执行相关检查。

## 实现

- 卡片使用业务标题、次级状态时间、头部完整对话入口、可滚动正文和淡分隔线下的关联名称。桌面最多三个名称，窄屏一个，紧凑模式保留对象入口和唯一的错误提示。
- 逐对象光环、船形轮廓、线和面高亮替代旧引导线及整组框。相机先只读预估，再按本轮问题与输入代次执行最多一次范围适配；单对象右上、多对象右侧、分散或空间不足顶部居中。
- 右侧抽屉提供搜索、类型筛选、每页 50 条、未定位提示和引用概要，与左侧详情独立存在。情报名称纯读详情；历史读取、刷新及重试统一局部 loading/error/代次管理，重试保留所选历史 ID。
- 对象清单按类型、标识、版本和来源任务合并，保留 missing 引用并单独提示 omitted 数量。实时定位复用船位呈现缓存，分析引用的观测时间与几何保持原快照。
- 全屏遮挡只计算全屏内部的实际控件；底部控件通过固定 CSS 基准和实际尺寸计算输入净空，保留图源署名与重试。Esc 捕获和普通快捷键分离，每次仅处理一层；关闭浮层按同一问题作用域恢复焦点。
- 地图实际高度低于 360px 时，图源长说明和完整图例进入向上展开的详情，常驻来源许可、准确比例尺和状态汇总。GIS 工具使用同一组按钮移入标题栏横向滚动行，卡片头部容纳展开、对话、重新聚焦和关闭操作。

## 审查与回归

独立需求和质量审查发现并修复了几何去重的二次方遍历、情报历史错误状态遗漏、单对象顶部卡片遮挡及 Esc 重复处理。相关场景均保留 RED→GREEN 证据。大对象去重以几何签名集合维护，同一输入每段只序列化一次。

浏览器回归按实际 trace 修复紧凑错误隐藏、键盘传播、全屏归属、焦点、底部净空和短屏工具遮挡，保留正文 40px、元素可点击、裁切、对象间距及相机稳定断言。关闭详情中的图例按真实可见性参与遮挡计算；长名称提示使用 Portal 并隔离地图快捷键。

历史键盘用例曾以缩放中间请求作为基准，最终视窗请求延迟返回后造成误判。用例现等待相机停止，并核对实际相机与最终请求的缩放及范围，再同时断言按键前后相机和请求不变。

单船顶部场景曾出现相机预留被截短、实际卡片仍保持较高尺寸的遮挡。现按净图区统一分配卡片和对象空间，右侧转顶部同样采用该预算；本轮已采用的卡片上限保留到新问题或重新聚焦，忙态结束和正文增长保持纯排版。极端空间不足时回执标记部分显示。
