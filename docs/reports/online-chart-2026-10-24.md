# 在线矢量底图与海标接入验证

## 接入结果

用户确认近期方案后，系统默认接入公开 OSM Shortbread v1 矢量底图和 OpenSeaMap 海标。在线底图提供海洋、水系、土地覆盖、道路、建筑、行政边界、中文地名和码头，保留深浅主题。图层位于 AIS、航迹、预测和证据之下，网络失败时使用现有全球与中国近海本地回退背景。

OSM 使用 `https://vector.openstreetmap.org/shortbread_v1/tilejson.json`，原生缩放 0—14，更高缩放采用 overzoom。OpenSeaMap 使用透明 XYZ PNG，客户端最大级别保守设为 18，社区覆盖按实际数据展示。文字使用 MapLibre 6.11.2 的本地字形能力，首期没有远程 glyph／sprite 请求及新增包依赖。常显署名包含 OpenStreetMap、OpenSeaMap 与 CC BY-SA 2.0 链接。

四个 Nuxt public 配置及环境变量见[图源使用说明](../maritime-gis.md)。OSM 底图和海标独立开关、独立回退，每个图源每次地图挂载最多人工重试两轮。持续没有返回的加载在 15 秒期限后回退，移动与新视口协调期限。主题更新和重试保留 Map、相机、AIS 及其他业务 source。

## 请求与失败边界

规格审查与首轮真实浏览器故障场景发现，MapLibre 6.11.2 会把矢量 HTTP 404 转为空瓦片，并把部分失败状态算作已加载；原始就绪检查会误报成功。现通过 MapLibre 公开协议接口处理在线请求，真实网络仍访问配置的原 HTTPS URL，保留正常浏览器缓存、Referer、User-Agent、缓存响应头及取消信号，非成功 HTTP 响应明确进入源错误。

人工重试只替换该在线组 source 和图层，分配新的代次 ID，保留当前主题 paint 与层序。旧 source 的错误和完成事件均无法改变新轮状态。协议按地图作用域注册，卸载时取消请求并释放，其他地图与业务源继续独立运行。

首轮还发现浅色文字精确 RGB 判定与实际抗锯齿字形不符，测试改为已定位中文 symbol 区域内的实绘检查，并保留海色、文字内容及同实例断言。原工作台用例在缩放动画中途保存基准，现等待移动结束与最终缩放查询；所有原有业务断言保留。第二轮发现原生展开署名遮挡重试，现以独立预留列、宽高约束和正常换行形成实体间距，保留按钮与署名链接操作。

## 浏览器验证

冻结源码在独立目录中构建生产包，独立 `.nuxt`、`.output` 与依赖缓存，构建成功。自动化通过独立 13003／13004 预览和本机 API 网关执行，原用户 13000／13001／13111 程序保持运行。常规测试默认关闭公共来源，在线专属测试使用自行构造的 MVT／PNG 并阻断未预期外部请求；没有下载公共瓦片作为离线 fixture。

最终使用实际 NVIDIA RTX 4060／Direct3D11，28 项浏览器用例全部通过，包括原工作台和页签 25 项，以及在线中文实绘、主题同实例、瓦片延迟回退、404 锁存、两个图源独立恢复和署名展开后的正常重试点击。前两轮软件渲染测试的失败日志、截图和 trace 保留，未覆盖或删除。

真实公共图源只在原 `13001` 独立登录上下文中做一次上海港代表区域验收：默认视图后一次原生 Shift 拖框至约 12.73884 级，范围约为 `[121.42765,31.19903,121.56487,31.27889]`。OSM TileJSON／MVT 的 22 个响应、OpenSeaMap PNG 的 66 个响应均为 200；正常缩放动画取消的请求单独记录。两个图源最终均就绪，地图实例保持，中文行政区、水系、道路及实际红绿海标清晰显示，无页面脚本异常。

公共验收保持正常 HTTP 缓存，未使用响应路由拦截、JavaScript 模块注入、HAR 或瓦片正文保存。只记录响应元数据、页面状态与带署名截图；该结果只说明此次代表视口可用，其他中国沿海区域和长期可用性继续依实际图源情况判断。

## 工程检查与运行

相关样式、状态和请求适配单测、根 TypeScript、Vue TypeScript、ESLint 与格式检查通过。全仓单测首次与软件浏览器并发时，未修改的预测领域文件出现 3 个 10 秒超时，其余 1,318 项通过；保留该次日志。浏览器关闭后以 `bun run test --maxWorkers=2 --reporter=dot` 独立复验，181 个文件、1,321 项全部通过，耗时约 66.53 秒。预测领域代码、断言和测试时限保持原样。

真实验收完成后浏览器和临时会话均退出；仅核验并回收 QA 专用 13003／13004 两个主进程，用户 API、Web 和预测 worker 保持原进程运行，HTTP 健康均正常。所有原始失败、最终构建、回归、真实图源和运行证据位于 Git 忽略目录 `.data/online-chart-integration/`，代表截图为 `public-shanghai-port.png`。本轮不包含新的性能压力结论，也不将社区地图作为专业 ENC 或航行安全资料。
