# 情报管理与海图标绘

情报工作台负责原文整理、审核、修订、对象关联和影响认定。态势海图负责筛选、选择、标绘与证据回查。采集来源、对象目录和人工判断通过稳定标识与情报版本关联。

## 使用入口

启动项目后，打开左侧“智能研判”中的“情报公告”。来源管理员可登记和启停来源；操作员可录入、审核、修订情报，维护地理对象和关联；只读用户可查询原文、使用标绘并保存自己的显示集合。

在态势海图左侧打开“情报标绘”。输入关键词、来源、类别、有效期、审核状态、目录对象或当前视野条件，点击检索。点击一条情报会加入标绘集合，并打开右侧详情；“定位”按钮用于移动海图视野。

勾选多条情报后批量加入。勾选跨页保留，筛选变化保留已标绘集合。集合中的每条情报可隐藏、恢复或移除；“清空标绘”清除个人显示集合，“定位全部”显示当前可见要素。刷新页面时恢复当前用户保存的情报版本引用。

## 原文、关联与影响

情报详情展示发布、有效期、来源链接、原文段落、采集归档及版本历史。审核记录独立于原文，修订产生新版本；旧版本与原文证据持续保留。

“发生位置”表达事件地点，“提及对象”表达原文提及，“涉及对象”表达证据中的对象，“适用范围”表达公告约束区域，“影响认定”记录人工判断的影响类型、范围、对象、有效时间与依据。

在右侧详情中选择目录对象，或绘制点、线、面，填写认定依据并引用原文段落。绘制完成后可进入编辑模式拖动顶点，保存关联后退出绘制。取消绘制清除本次草稿。影响认定另需填写影响类型及起止时间。

点选海图上的情报几何、目录对象或标签，可以回看相关情报。重叠要素提供选择列表。位置、对象、影响、待核实候选和对象目录具备独立图层开关；历史要素与实时 AIS 船位分别标注时间。

地图最多显示 120 条情报文字标签和 120 个目录对象文字标签，空间几何仍参与绘制和点选。批量标绘最多引用 1000 个情报版本，几何总量受接口限制；超出时拆分选择集合。

## 审核与时间

自动提取、别名匹配和空间相交形成候选。操作员确认事件与关系后，满足专题类别、有效期和规则的证据进入正式计算。审核改变会通过持久通知触发相关专题重新计算。

公开新闻的索引时间和缺少明确有效期公告的发布时间用于采集观测。详情显示“实际时间待确认”，操作员需先修订并填写实际有效时间，再确认情报。表单及筛选中的时间输入标明 UTC；详情按界面时间格式展示。

修订表单保留来源归档与旧业务范围。可选择沿用上一版本关系，沿用关系进入待核实状态并记录上一版依据，支持再次确认。船舶的历史关联位置与最新 AIS 观测分别表示，目录维护的船名和别名在兼容公告导入后继续保留。

## 接入与参考资料

```powershell
bun --no-env-file run migrate
bun --no-env-file run intelligence:sources register
bun --no-env-file run intelligence:sources ingest
```

命令使用进程环境配置基础设施。使用本机 `.env.local` 时，显式运行 `node --env-file-if-exists=.env.local --import tsx scripts/workspace.ts <命令>`。预置来源注册默认保留已有配置，`--replace` 用于明确替换。采集服务根据来源轮询频率持续接入，单轮入口与轮询服务共享来源锁。

来源细节与实际联网状态见[公开海事情报采集](intelligence-ingestion.md)；五个本地参考仓库的提交、许可证和参考模块见[开源情报参考仓库](osint-reference.md)。外部来源错误、部分失败、待结构化数量和最后采集时间可在来源管理中查看。

## 接口与兼容

接口统一位于 `/api/v1/intelligence`，使用既有会话、Origin 和 CSRF 校验。

| 接口                                                                          | 职责                                                       |
| ----------------------------------------------------------------------------- | ---------------------------------------------------------- |
| `GET/POST events`                                                             | 情报筛选和结构化录入；`latest=true` 查询每份情报的最新版本 |
| `GET events/:id`、`POST events/:id/review`                                    | 原文、关系、历史及独立审核                                 |
| `POST events/:id/relations`、`PUT relations/:id`、`POST relations/:id/review` | 关联与影响的追加、修订和审核                               |
| `GET/POST objects`、`PUT objects/:id`、`POST objects/import`                  | 对象检索、维护和原子 GeoJSON 导入                          |
| `POST plot`、`GET/PUT plot-set`                                               | 批量空间要素查询与个人显示集合                             |

旧接口省略 `latest` 时继续返回历史版本。旧公告的区域框转换为适用范围，MMSI 转换为对象关联，并标记兼容转换来源。增量迁移 `008` 建立对象、关系、审核和显示集合；`009` 保存每轮采集统计，`010` 为早期数据库补齐来源链接和几何有效性约束，`011` 保存最后成功采集时间。采集原始字节、情报原文与修订历史保留独立证据。
