# 智能体会话与账号记忆

## 设计与组件取舍

记忆使用现有 PostgreSQL 保存，由任务提交和执行宿主组装上下文。会话记忆负责当前对象、条件、指代和任务进展；账号记忆负责用户确认的跨会话偏好。船位、航迹、航线和事件仍以业务记录及其版本为依据。

架构参考 [LangGraph 的会话检查点与跨会话 Store](https://docs.langchain.com/oss/javascript/langgraph/add-memory)，按会话与账号划分作用域。重要的当前状态优先进入上下文，远期内容按需读取，参考 [Letta 记忆分层](https://github.com/letta-ai/skills/blob/main/letta/agent-development/references/memory-architecture.md)。记忆原文与模型投影分别处理，沿用现有模型数据投影边界。

本轮对 Mem0 TypeScript 发布包 `mem0ai@3.3.1` 做了静态接口核查。它提供 `add`、`search`、`update`、`delete`，`add` 可指定 `infer`，检索可携带用户过滤条件；单条 `get/update/delete` 以记忆 ID 为参数。应用仍需负责真实账号鉴权、候选确认、修订冲突、业务事务和删除代次。发布包证据位于本地忽略目录 `.data/memory-component-evaluation/`，未加入生产依赖。参考 [Mem0 开源仓库](https://github.com/mem0ai/mem0)。

本期采用项目内 PostgreSQL 实现，复用事务、任务恢复和界面权限。后续引入 Mem0 等提取／检索组件时，通过宿主记忆边界接入，正式记录仍受本项目确认和权限规则约束。本轮组件评估属于接口与代码核查，真实模型提取质量、召回效果及计费对比另行验证。

## 使用规则

- “高亮某型号船舶”产生可追踪的对象集合；下一轮“聚焦”“统计刚才这批”“查它们的航迹”优先继承集合身份。
- 对象解析顺序为本轮明确对象、提交时选择、当前会话最近兼容对象。账号常用对象通过明确引用使用。
- 历史查询解释采用结果快照；实时定位读取有效船位并展示观测时间。超出现有工具容量时提示缩小范围。
- 清除高亮保留讨论对象；“忘掉刚才这批船”清理对应会话指代。
- “记住：以后回答简短一点”明确保存账号记忆。自动识别到的稳定偏好进入待确认区，确认后参与跨会话召回。
- “记住这个区域叫珠江口观察区”将提交时的明确区域或会话区域保存为命名范围；新会话可说“聚焦珠江口观察区”。“记住选中的船舶叫观察船队”保存对象身份，后续明确引用“观察船队”即可使用。
- 记忆管理位于“我的记忆”，支持查看、编辑、候选确认／拒绝、删除、清空，以及分别暂停长期记忆读取和自动建议。
- 只读业务账号可维护个人记忆。Agent 对话与业务工具继续沿用现有账号权限。

## 存储与恢复

新增迁移 `026`。会话状态、对象集合与成员、账号设置与记忆、操作回执、审计元数据和任务记忆快照分别保存。成员完整性由宿主维护，模型读取有界摘要。

每轮任务固定输入修订对应的会话和账号记忆版本。会话顺序号与修订校验防止迟到结果覆盖新状态；删除或暂停后的代次检查防止旧任务重新写入。记忆操作使用 `operationId` 幂等键及 `expectedRevision`，同键不同请求或过期修订报告冲突。

上下文由最近八个普通任务轮次、增量语义摘要、当前对象数量和最多十条相关账号记忆组成，最终模型投影最多 6,000 个字符。账号管理命令先排除再选取近期轮次。所有模型路径使用同一脱敏投影，完整对象身份和空间计算由宿主管理。界面显示本轮检索到的账号记忆；模型实际输入还会受投影预算裁剪。

本地 provider 使用明确用户表达提取稳定偏好，以候选形式同步入库；摘要使用本地主题、条件和结果来源增量更新。对象与条件、候选、任务快照在现有事务链路中保存。后续接入需要模型调用的提取器时，应将耗时调用移出持锁事务，通过有代次校验的后台流程提交候选。

账号正式记忆与待确认候选分开召回。候选默认 30 天到期。删除擦除在线记忆正文及相关派生快照，操作和审计保留必要元数据。原始聊天、业务产物与备份按各自生命周期管理；记忆删除不等于聊天记录或备份删除。

## 部署配置

先应用迁移，再启动包含记忆代码的 API 与 Agent，刷新前端。

| 环境变量                         | 默认值 | 作用               |
| -------------------------------- | ------ | ------------------ |
| `AGENT_SESSION_MEMORY_ENABLED`   | `true` | 会话对象与条件记忆 |
| `AGENT_ACCOUNT_MEMORY_ENABLED`   | `true` | 账号长期记忆       |
| `AGENT_MEMORY_PROPOSALS_ENABLED` | `true` | 自动生成待确认建议 |

账号设置中的 `readEnabled` 控制长期记忆召回，`proposalsEnabled` 控制自动候选。用户明确管理记忆使用独立写入流程；系统关闭账号记忆时仍提供清理入口。
