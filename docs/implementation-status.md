船舶高亮与镜头控制已接入本页任务组、最新船位刷新、动态 Skill 和真实地图回执；使用方法见[地图技能](agent-map-skills.md)，数据库回归、真实浏览器闭环及历史磁盘故障记录见[专项核验](reports/agent-map-skills-2026-10-17.md)。

个人动态技能本轮通过 114 文件／837 次单元执行、29 文件／175 项集成检查（另有 2 项既有跳过），并通过真实模型自主发布与零模型复用烟测；浏览器、构建和部署静态检查边界见[专项核验报告](reports/agent-dynamic-skills-2026-10-17.md)。下文保留架构审查阶段的历史基线。

架构审查阶段的现有代码回归记录为 92 个测试文件、704 次测试执行通过，全工作区 lint 与 typecheck 通过。已发现 intelligence-runtime.test.ts 导入 runtime.test.ts，导致其中 48 项重复注册；704 反映运行器执行次数，不能解释为 704 个独立场景。去除已确认重复后为 656 次非重复执行计数，也不等同于覆盖率。BASE 任务将先拆分共享测试夹具并重新建立基线。

全量格式检查发现既有格式问题，本轮按文件写域检查修改内容。历史构建、数据库集成、浏览器和真实模型验收按各报告的代码日期与环境读取。本轮最终命令、Docker/K8s 校验及未执行事项以[2026 年 10 月 17 日交付报告](reports/deployment-delivery-2026-10-17.md)为准。

## 待实施优先级

- BASE：执行阶段权限、采集必传租约、重复测试注册与行为基线。
- APP / PROTOCOL：最小共享授权和业务用例、通用身份与协议、构建发布边界。
- SERVER / BROWSER：统一执行、动态技能、预算与调用原子记录、审批恢复、浏览器生命周期。
- VERTICAL / COVERAGE：先完成查询、普通编辑、高风险确认、跨页导航，再按能力目录覆盖现有页面与 API。
- REMOTE / PACKAGE / RELEASE：远程只读优先、写入对账、四包独立消费、AIS 兼容迁移与回滚。
- EVIDENCE：真实来源、生产容量、外部对象存储、保留策略与恢复演练。

各任务的前置依赖、责任写域、接口、测试、完成条件和迁移回滚由路线图统一维护。
