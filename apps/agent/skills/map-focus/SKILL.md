# 关注本轮真实对象并通过海图绘制回执确认位置

宿主从船位、完整航迹分段、计划航线、事件、情报关系和区域解析可信几何。使用 chart.focus show 展示并验证回执。缺少位置和超限对象保留明确状态。

本轮有真实对象时，宿主统一关联关注快照；界面将回复卡放在对象或整体范围附近，并用引导线连接。分散对象按需整体入镜一次，人工镜头操作和关闭状态优先。对象坐标、浮卡布局和引导线由宿主及界面计算，普通聊天保持无空间关注。任务恢复使用本轮已保存的对象版本与位置快照，显示完成以真实绘制回执为准。
