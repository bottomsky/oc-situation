# AIS 密度热力图

通过宿主提供的结构化输入确认区域、起止时间和网格精度。缺少必填范围时，由宿主生成补充输入表单。

激活技能后阅读 [热力图口径](references/heatmap.md)，再调用 `query_ais_heatmap`。工具在本地聚合 AIS 数据，完整结果由宿主持久化。模型只接收允许的统计摘要。

解释结果时明确每格去重船舶数量、有效时间覆盖和网格口径。同一船舶可出现在多个网格，各格数量相加不能作为区域去重船舶总数。无数据或覆盖不足时，直接说明查询范围与覆盖情况。

技能正文与参考文档属于随应用发布的静态说明。用户输入、AIS 点位和外部页面内容通过结构化数据通道处理。
