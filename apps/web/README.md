# 海图 Web

Nuxt 4、Nuxt UI 4 与 MapLibre 构成中文团队操作台。页面通过同源 `/api/v1` 查询真实服务，数据存储客户端由后台服务使用。

## 本地运行

在仓库根目录使用 Bun 安装依赖，并按照根目录部署说明启动基础设施与样例流水线，再运行 `bun run dev:web`。访问 `http://127.0.0.1:13001`。

开发代理将 `/api` 转发至 `http://127.0.0.1:13000/api`，保留请求 Origin。生产由 Caddy 提供同源路由。账号通过后台管理员引导或样例流程创建。

## 功能

- 船位地图：视窗查询、网格聚合、来源及船型筛选、24 小时至 30 天范围、5 秒轮询与暂停、陈旧和截断提示。
- 船舶：游标搜索、最新船位、字段来源、报告时间和接收时间、样例及质量标识。
- 轨迹：UTC 起止时间、最多 5,000 点、服务端分段、抽稀和截断提示、播放与时间滑块。
- 治理：来源配置、任务配置与运行控制、持久运行记录、隔离原文、质量统计、归档重放、账号角色管理。
- 权限：只读、操作员、管理员对应入口；后台再次校验角色、CSRF 与同源请求。

## 地图与类型

海图固定使用本地深色矢量样式和仓库内 Natural Earth 公共领域陆地数据。深色海面、陆地与海岸线一次加载，船位、轨迹和专题证据分别叠加；地图背景由前端本地资源提供。图层控制管理三类业务图形。

MapLibre 6 的 Worker 经 Vite `?worker&url` 打包，浏览器验收检查地图实际加载状态。公共业务类型来自 `@ais/contracts`；治理接口类型从 `apps/api/openapi.json` 生成至 `app/types/api.generated.ts`。接口变更后重新生成该文件。

## 验证

`bun run typecheck`、`bun run build`、根目录 Vitest 和 Playwright 入口负责验证。端到端测试要求真实样例流水线运行，根配置从忽略的 `.data/demo-admin.json` 读取测试账号，测试代码保留所需环境变量入口。生成的截图、浏览器轨迹及凭证文件由 Git 忽略规则管理。

Windows 沙箱可能阻止 Nitro 对用户目录执行符号链接读取，表现为 `EPERM readlink`。该场景使用授权的沙箱外构建；运行时与应用源码无需修改。
